# ☁️ AI Cloud Cost Optimizer

An AI-powered Cloud FinOps assistant built with Streamlit, Pandas, Plotly, and OpenAI. 
This web application parses multi-cloud billing files (AWS, Azure, GCP) to generate spend visualizations and automated AI recommendations for cost reduction.

## Features
- 📊 **Multi-Cloud Billing Visualizations**: Interactive pie charts and bar graphs using Plotly.
- ⚡ **Key Spend KPIs**: Instantly calculates total monthly spend, top cloud provider, and highest-cost services.
- 🤖 **AI-Driven Optimization**: Generates actionable cost-reduction strategies using OpenAI.
- 📁 **CSV Upload Support**: Parse custom cloud billing exports or test with default sample datasets.
